Orientation rules

Reference · critical

Remote Control faces the drills

The script flies by the Remote Control's frame, so its forward is the mining direction. The "eye" goes in front and the gap on top. If you add a cockpit, put [FM Ref] in the Remote Control's name so the script never picks the cockpit.

Drills · critical

All drill bits forward

The script measures the drill bank in the Remote Control's frame. The bank's width and height set shaft spacing (here 3 m × 3 m). Its forward reach sets where cutting starts. Mixed facings break both.

Docking · critical

One dock connector, ring outward

Name it [FM Dock]. Any face of the hull works, because docking is solved from the connector's own frame. The rear keeps the drills pointing away from the carrier. Nothing may stand behind its ring. The small-grid Connector mates with a carrier's large-grid connector.

Camera

Lens along the drill axis, clear view

Name it [FM Cam]. It ranges the rock face, runs the survey and checks for obstacles ahead. An untagged camera is only used if it points within about 8° of forward. Mount it above the drills, not behind them.

Thrusters

Every push direction covered

The self-test fails without at least one working thruster per direction. In Space Engineers thrust doesn't twist the ship, so the layout needn't be symmetric. Only the count per direction matters. Keep flames off the drills and the camera.

Stone dump

Sorter feeds ejector, ejector faces out

Both carry [FM Eject]. The script sets the sorter to a stone whitelist with Drain All, and opens the ejector only while mining. Point the ejector away from the hull and the camera's view. The self-test's Stone dump path line confirms the conveyor link.

Antenna

Broadcasting, mast clear

Turn broadcast on. With AntennaAuto the script sets its range itself (distance home × 1.5). Mount it high so the hull doesn't shade it.

Power

Batteries on Auto

Leave them in Auto. The carrier's pad charges them through the connector. The script learns the drain per metre and per tonne, and turns home with EnergyMargin to spare.

Commissioning

SHEET 6 / 6 · Terminal setup and first flight

Build order

  1. Layer Y0–Y5, Z0–Z1 (aft slab): place the connector and three batteries. Start with the connector at the bottom-left of the rear face.
  2. Z2–Z4: four medium cargo containers. Each one's back port meets the connector or a battery face. The lower-left one sits on the connector's conveyor port.
  3. Z5–Z10: four drills, bits forward, each fed straight into the container behind it.
  4. Y6 (utility deck): Remote Control (eye forward, gap up), programmable block, six gyros, camera and sensor at the front edge, lights and decoy at the rear. Fill the rest with light armor.
  5. Antenna on the deck's rear-left corner (X0, Z0), mast up.
  6. Pods: 2 × 2 × 7 armor spines on both sides (Y2–Y3, Z2–Z8), then 22 thrusters per pod, as sheet 3 shows layer by layer.
  7. Belly: small conveyor sorter under the lower-left cargo (X1, Y−1, Z3), ejector below it facing down.

First flight

  1. Recompile and run selftest while docked. Fix every FAIL. Flight control warns until a carrier is in range.
  2. In open space, run hold, then turn, turn up and turn roll. Each should settle 45° the right way. If an axis turns the wrong way, use set InvertYaw on (or Pitch / Roll).
  3. Aim at a rock face within 100 m and run setsite, then start. return brings it home.
  4. Optional: an LCD named [FM Menu] plus four toolbar slots running the PB with up, down, select and back.

Variants

  • Planets: for charted ground sites the drone points its nose straight down. The back thrusters (flames toward the drills) then hold it up. Check the "nose-down" lift on sheet 5: the script turns home below MinLift 1.25.
  • Hydrogen: swap ions for hydrogen thrusters and add H2 tanks. The script tracks tank level next to battery charge.
  • Mining lasers: replace the drills with forward-facing lasers. Keep the [FM Cam] camera next to them, because the beam only fires on a clear path.
  • Evasion: add an AI Defensive block named [FM Flee] and an AI Move block anywhere inside.
